# AmuzASCII / AmuzAnyToolkit

Полный редактор теперь входит в единый репозиторий AmuzAnyToolkit. Запускайте сервер и сборку **из корня монорепозитория** по [основному README](../../README.md). Студия доступна на `/ascii/`, её API — на `/api/*`.

Shared UI kit: [documentation](../../ui-kit/README.md). Detailed ASCII feature guide: [docs/guide.md](docs/guide.md).

Original source: https://github.com/listoCheck/AmuzASCII-studio/tree/master. This directory contains normal source files, not a submodule. Its standalone container configuration was replaced by the root Dockerfile and compose.yaml.
