# Amuz UI kit

Общие стили находятся здесь; каталог подключается в работающие приложения, а не только служит примером. Галерея компонентов: `/ui-kit/` после запуска корневого `run.py`.

| Файл | Назначение |
| --- | --- |
| `tokens.css` | Палитры всех 12 тем, отступы, радиус, шрифтовые стеки |
| `themes.js` | Единый реестр тем: идентификатор, название, цвета превью, акцент |
| `scrollbars.css` | Полосы прокрутки из ASCII, включая hover/active, touch и forced-colors |
| `components.css` | Базовые элементы, кнопки, панели, строки и сигнальный блок |
| `appearance.js`, `appearance.css` | Панель выбора тем с мини-превью, палитрами и настройками интерфейса |
| `appearance-state.js` | Валидация и миграция сохранённых параметров оформления |
| `ascii.css` | Адаптер специфичных компонентов ASCII к общим темам |
| `index.html` | Интерактивная галерея для просмотра и проверки тем |

## Подключение нового инструмента

Для обычного HTML подключите `/ui-kit/components.css`. Для Vue импортируйте CSS по относительному пути из исходников: Vite включит его в сборку. ASCII использует `ascii.css`, который подключает те же `tokens.css` и `scrollbars.css`; хаб и Морзе — `components.css`.

```html
<link rel="stylesheet" href="/ui-kit/components.css">
<section class="amuz-panel">
  <div class="amuz-label">НОВЫЙ ИНСТРУМЕНТ</div>
  <div class="amuz-row">
    <button class="amuz-button primary">Начать</button>
    <button class="amuz-button" disabled>Недоступно</button>
  </div>
</section>
```

Тема задаётся через `document.documentElement.dataset.theme`. Идентификаторы: `paper`, `midnight`, `ocean`, `plum`, `graphite`, `peach`, `blueprint`, `acid`, `mars`, `neon-city`, `neon-circuit`, `cyberpunk`. При выборе темы установите также `--ui-accent` из реестра `themes.js`. ASCII дополнительно вычисляет контрастный `--ui-accent-text` в `preferences.js`.

## Токены

| Токен | Использование |
| --- | --- |
| `--paper`, `--ink`, `--line` | Фон страницы, текст, границы |
| `--ui-muted` | Вторичный текст |
| `--ui-field`, `--ui-elevated`, `--ui-workspace` | Поля, панели, рабочая область |
| `--ui-soft`, `--ui-hover` | Мягкое выделение и наведение |
| `--ui-accent`, `--ui-accent-text` | Основное действие и текст на нём |
| `--ui-radius`, `--ui-scale` | Скругление и масштаб |
| `--amuz-space-1` … `--amuz-space-5` | 4 / 8 / 16 / 24 / 32 px |
| `--amuz-font`, `--amuz-mono` | Основной и моноширинный шрифт |
| `--scrollbar-thumb`, `--scrollbar-hover`, `--scrollbar-active`, `--scrollbar-track` | Прокрутка в выбранной теме |

Не копируйте палитры в новые приложения. Добавляйте тему в `themes.js` и `tokens.css`, специфичные декоративные эффекты — в адаптер инструмента. Глобальные стили `ascii.css` предназначены только для ASCII и не подключаются в хаб. Сохраняйте клавиатурный фокус, подписи полей и disabled-состояния. Цвет изображения и сигнала не должен меняться из-за случайного глобального фильтра.

Настройки ASCII сохраняются под существующим ключом `AmuzASCII.ui.v1`, настройки хаба — `amuz.theme`. Приложения используют общие определения тем, но сохраняют выбор независимо.


## Визуальный выбор оформления

В хабе, Морзе и галерее UI kit кнопка «Оформление» открывает общий диалог: 12 карточек с мини-превью, цветовые образцы и выделение активной темы. Изменения применяются сразу; доступны акцент, размер текста, плотность, скругление и ширина боковой панели Морзе. Закрытие: «Готово», крестик, Escape или клик по фону. Сброс затрагивает только оформление.

Подключите `appearance.css`, затем импортируйте `mountAppearance` из `appearance.js` и передайте кнопку. Для инструментов со звуком/вводом передайте обработчик `onOpen`, приостанавливающий ввод. Настройки хранятся в `amuz.appearance.v1`, старый ключ `amuz.theme` автоматически переносится и поддерживается для совместимости. Настройки ASCII и учебный прогресс не изменяются.

```js
import {mountAppearance} from '/ui-kit/appearance.js';
mountAppearance(document.querySelector('#appearance-trigger'));
```
